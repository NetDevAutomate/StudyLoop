# Superseded release drafts

These notes were written for internal versions that were **never published** —
no git tag, no PyPI release, no installable artefact. When the project was
rebased to `0.1.0` for its first public release (see `releases/v0.1.0.md`), the
versions they describe ceased to exist as release targets.

They are kept because they record what was planned and shipped during
development, which the CHANGELOG summarises but does not narrate. Nothing here
describes a version anyone can install.

Note that `v2.5.0-unreleased.md` refers to "the publish workflow" — there is no
publish workflow in `.github/workflows/`. That was aspirational at the time of
writing.

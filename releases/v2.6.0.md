# v2.6.0 Release Notes Draft

## Summary

`studyloop v2.6.0` adds an opt-in Obsidian vault export to `session-export`: AI
coding sessions can now be mirrored into your Obsidian vault as structured,
Dataview-ready Markdown — with `[[wikilink]]` backlinks and per-project index
notes — alongside the existing SQLite export. The release also refreshes user
docs, architecture C4 diagrams, and the config reference to match.

## Highlights

- **Obsidian session-memory export** (`session-export --obsidian`): writes one
  Markdown note per session into `<vault>/AgentMemory/`, with Dataview frontmatter
  (`type: agent-memory`), `[[wikilink]]` backlinks to matching vault topic notes,
  and per-project MOC index notes. Tool-agnostic across Claude/Kiro/Gemini/Codex/
  OpenCode/pi/omp.
- **Idempotent + incremental**: a content hash in each note's frontmatter skips
  unchanged sessions. A normal run exports only sessions touched that run;
  `--obsidian-backfill` does the one-time full-history import.
- **New flags**: `--obsidian` / `--no-obsidian`, `--obsidian-vault PATH`,
  `--obsidian-backfill`, `--obsidian-dry-run`.
- **Config**: new `obsidian:` section in `config.yaml` (`export_enabled`,
  `vault_path`, `memory_dir`, `moc_dir`, `backlinks`, `granularity`). Coexists with
  the existing flat `obsidian_base` study-source key; read by both config loaders.
- **Setup wizard**: `studyloop setup` now offers to enable export at the Obsidian
  step and checks for the `.obsidian/` vault marker.
- **Doctor**: `check_obsidian_vault` now validates the `.obsidian/` marker; new
  `check_obsidian_export` confirms the memory directory is writable when enabled.
- **Hardening**: the writer sanitises untrusted session fields and enforces a
  containment guard so nothing can be written outside `AgentMemory/`.
- **Docs**: new "Obsidian Vault Export" reference page, updated setup guide, CLI
  reference, system overview + current-architecture C4 container diagram, and READMEs.

## Upgrade Notes

- Existing source installs refresh with:

```bash
uv sync
uv run studyloop doctor --fix
```

- The feature is **off by default**. Enable it per-run with `--obsidian`, set
  `obsidian.export_enabled: true` in `~/.config/studyloop/config.yaml`, or answer
  yes at the `studyloop setup` Obsidian step.
- First-time users who want their whole history mirrored should run a one-time
  `session-export --obsidian --obsidian-backfill` (idempotent; safe to repeat).

## Recommended Callouts

- Notes land in a dedicated `AgentMemory/` folder, kept separate from curated
  study notes so machine-generated memory never dilutes them.
- The Obsidian + session-DB **GraphRAG** layer (unified retrieval over vault
  embeddings + sessions) is scoped but not shipped — see
  `docs/designs/obsidian-graphrag-roadmap.md`. It is gated on resolving the
  vault/session embedding-space mismatch (bge-micro-v2 vs all-mpnet-base-v2).

# Prospective small-pilot protocol (not yet executed)

Purpose: determine whether the current retriever finds required evidence on a
small real sample without pretending the synthetic demonstration is efficacy.
Freeze this protocol and record any deviations before inspecting arm results.

1. Choose 3–5 naturally occurring questions from a decision/discussion lineage
   not used in development. Existing StudyLoop/MailGraph demonstration lineages
   remain excluded. The learner need not write a large questionnaire.
2. Freeze an eligible corpus snapshot, source identities, explicit scope/time,
   query wording and known capture gaps. Record counts and content size. Do not
   infer work/personal scope from harness or host.
3. A reviewer who has not seen arm outputs marks relevant passages and required
   exact evidence spans. Record reviewer, rationale, alternatives and disagreement.
   The scorer author must not silently act as an independent labeler. If no
   independent review is available, label the set development/candidate.
4. Check that each required set really is indispensable. The current AND-only
   span format cannot represent alternative sufficient sets. Exclude such cases
   from this small pilot with explanation or extend the format before freezing.
5. Freeze data and settings before running. Use keyword, reviewed relationships
   and the seeded rewired control at the same byte ceiling. Verify input/code
   hashes and report all cases, including failures and missing evidence.
6. Review paired results: missing evidence, counterevidence, irrelevant additions,
   invalid references, time/scope failures and added context. Report the small
   sample and uncertainty; no threshold chosen after seeing the scores.
7. If results justify a larger trial, reserve fresh lineages. Once outcomes are
   inspected, this pilot is development evidence for any subsequent tuning.

Labels describe evidence present in the eligible corpus, not whether the underlying
claim is objectively true. Where validated claims are the objective, enumerate
actual test/output artifacts, versions and environments separately. Missing
artifacts must remain a limitation, not be replaced by confident session prose.

This protocol does not authorize sending private corpus bodies to an external
model. Council can review aggregate outcomes and sanitized methods. Learner-facing
answer trials require separately controlled model/prompt/token settings and the
EXPLANATION-RUBRIC.md assessment. No such trial or held-out dataset has been run.

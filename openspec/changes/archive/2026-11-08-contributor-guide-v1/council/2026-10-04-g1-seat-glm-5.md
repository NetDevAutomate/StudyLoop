## 4. What the plan missed

**Two things a contributor needs in their first week that none of the twenty pages answers:**

1. **How to run the test suite on a machine with a different Python version (e.g., 3.11 vs 3.12).**
   - Evidence: contributor-environment.md:10 says "Python 3.12 (`.python-version`)". It does not explain what to do if your system has 3.11 or 3.13.
   - The drift test and receipts show Python 3.12.8, but the guide does not explain how uv handles this (it installs the pinned version).
   - Real need: a contributor on a system without 3.12 will see `uv sync` fail or install 3.12 for them. The guide should say so.

2. **How to run a single browser test locally without the full e2e suite (which takes ~8 minutes).**
   - Evidence: contributor-testing.md:38 says "The browser twin of that example runs under `just e2e` with the file path as its argument".
   - contributor-web.md:59 says "run it focused with the cookbook's `just e2e <file>` form once, on your own machine".
   - But there is no example command showing `just e2e packages/studyloop/tests/e2e/test_one_file.py`.
   - The Justfile shows `e2e *ARGS` accepts args, but the guide does not show the syntax clearly in one place.
   - Real need: a contributor fixing one web test does not want to run the full 8-minute suite.

**Two claims I expect other seats to make that the repository contradicts:**

1. **Claim: "The guide does not explain how to handle merge conflicts."**
   - Repository contradiction: contributing.md:43 says "Before a second contribution, fetch upstream and branch afresh; do not stack unrelated changes on your first PR, and never discard uncommitted work to synchronise a branch."
   - This is not a merge-conflict guide, but it IS a strategy to avoid them. The claim is weak.

2. **Claim: "The guide does not explain how to revert a commit."**
   - Repository contradiction: The guide is about contributing, not git operations. The repository does not need a revert guide in the contributor docs. This claim would be rejected as out of scope.

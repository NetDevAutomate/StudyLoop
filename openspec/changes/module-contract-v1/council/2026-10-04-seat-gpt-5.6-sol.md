## Q4

1. **Attack:** `--yes` pre-authorizes execution before the displayed command is read; code prints the command and then lets `yes` short-circuit interaction (`/Users/ataylor/code/personal/tools/studyloop/packages/studyloop/src/studyloop/cli/_practice.py:77-87`). **Fix:** Web consent must return a one-use challenge bound to exact digest, argv, phase, target and expiry after display; no `--yes` equivalent.
2. **Attack:** R-15b compares only command text, so `scripts/check.sh` can change or become a symlink after approval (`/Users/ataylor/code/personal/tools/studyloop/packages/studyloop/src/studyloop/learning/practice.py:274-285`). **Fix:** snapshot first, reject links/non-regular files, hash all referenced content, and re-check the snapshot digest at spawn.
3. **Attack:** shell syntax, PATH replacement, ambient HOME, inherited credentials and network access turn a “relative script” into arbitrary host execution; the current runner uses `shell=True` (`/Users/ataylor/code/personal/tools/studyloop/packages/studyloop/src/studyloop/learning/practice.py:282-287`). **Fix:** use `shell=False`, strict argv grammar, scratch HOME/XDG, minimal PATH, credential-scrubbed allowlist, and sandbox policy.
4. **Attack:** declaring `check` or `cleanup` does not constrain what its script does; an admin cleanup can delete any resource reachable through its kubeconfig. **Fix:** bind each phase to a core-owned target/credential, use disposable clusters in v1, and make target teardown a core operation rather than module shell code.
5. **Attack:** a LAN page can forge a command POST or replay stale consent unless HTTP origin, CSRF, active-session and attempt identity are normative; current exact-origin logic is only consumed by WebSocket routes (`/Users/ataylor/code/personal/tools/studyloop/packages/studyloop/src/studyloop/web/routes/session/_ws.py:77`; `/Users/ataylor/code/personal/tools/studyloop/packages/studyloop/src/studyloop/web/ws_origin.py:18-41`). **Fix:** require same-origin POST, CSRF token, Basic-auth session, one-session claim, nonce and replay rejection.
6. **Attack:** unlimited capture enables memory exhaustion, and hostile stdout can leak secrets or prompt-inject the mentor; current persistence truncates only after capture (`/Users/ataylor/code/personal/tools/studyloop/packages/studyloop/src/studyloop/learning/practice.py:167-168,282-287`). **Fix:** stream with byte/time caps, redact before persistence/delivery, preserve truncation metadata, and never interpolate raw output as mentor instructions.

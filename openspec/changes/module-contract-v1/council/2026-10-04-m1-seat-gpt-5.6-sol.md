# M1 defensive review — gpt-5.6-sol

Revision `713194dc` confirmed. Unavailable: `@mochi:mochi` (declared but not configured; not needed). ADR-0012 was absent from the permitted trees; its binding M0 arbitration was present.

## 1. Shell and argv

`Popen` receives a list with `shell=False`. Static `..`, absolute, nested, symlink, hardlink, directory, non-executable, and outside-`scripts/` cases are refused. Lane C rejects source symlinks/hardlinks; its snapshot enumerator skips symlinks rather than copying targets.

**DEMONSTRATED** `packages/studyloop/src/studyloop/modules/runner.py:113-137` -- a deck-controlled NUL or multi-megabyte single argument passes the 64-item check, then spawn raises uncaught `ValueError`/`E2BIG` after consent -- reject NUL and cap total encoded argv bytes before prompting/spawn; convert spawn failures to `PhaseResult(ERROR)`.

**WEAKNESS** `packages/studyloop/src/studyloop/modules/runner.py:413-425` -- digest redemption and pathname execution are separate operations; same-UID code can replace the supposedly immutable snapshot file in that window (Lane C leaves snapshot directories owner-writable) -- execute a verified open descriptor/copy inside an OS-enforced sandbox and verify the snapshot digest at every lookup.

## 2. Environment

The explicit `env=` mapping contains only scratch HOME/XDG, drill identity, minimal PATH, and conditional KUBECONFIG; it does not copy `os.environ` directly.

**WEAKNESS** `packages/studyloop/src/studyloop/modules/runner.py:203-231` -- scratch HOME/cwd are not containment: the hostile process runs as the learner and can read/write user-accessible files, inspect same-user processes (including parent environment where the OS permits), use network, and re-exec arbitrary absolute binaries -- require an OS sandbox/separate low-privilege identity with filesystem, process, and network policy, or treat modules as trusted code rather than hostile.

**RULING** `packages/studyloop/src/studyloop/modules/runner.py:94-97` -- Apple-silicon Homebrew `kubectl` at `/opt/homebrew/bin` is absent, while adding all Homebrew binaries would violate least privilege -- core should resolve each declared prerequisite to a canonical executable, build a per-attempt allowlisted bin directory containing only those tools, and prepend it to `/usr/bin:/bin`.

## 3. Consent

The ledger binds attempt id, phase, exact argv, script digest, and target; marks redemption before checks; expires at 600 seconds; and is process-local. CLI confirmation is explicit and `--yes` is absent. The remaining digest-to-exec race is finding 2.

## 4. Caps, timeouts, kill

Streaming bounds stdout to 64 KiB, stderr to 16 KiB, and total newlines to 2,000; it also bounds post-EOF wait. SIGTERM then SIGKILL is sent with `killpg` to the child-led session.

**WEAKNESS** `packages/studyloop/src/studyloop/modules/runner.py:234-251` -- confirmed: a grandchild calling `setsid()` leaves that process group and survives both signals -- pure portable Python cannot reliably contain a daemonised descendant; use Linux cgroups and a macOS sandbox/job boundary (or a VM), with platform-specific executor tests.

## 5. Redaction and recording

The scrubber covers AWS access/secret keys, GitHub PAT/fine-grained/OAuth tokens, OpenAI and Anthropic keys, JWTs, private-key headers, credentialed postgres/mysql/mongodb/redis URLs, GCP keys, Stripe keys, Slack bot tokens, and quoted generic secrets. The DDL has no output/learner-text columns; `record_phase` inserts only `practice_check_events` and writes no observation/progress/review row. Redacted stdout/stderr are separately persisted in the attempt sidecar.

**DEMONSTRATED** `packages/studyloop/src/studyloop/modules/runner.py:297-309,452-458` -- truncation precedes regex redaction, so a cap-cut `ghp_aaaaaaaaaaaa` fragment survives unchanged -- stream-redact with a maximum-pattern overlap buffer and replace any unresolved boundary fragment before retaining/showing it.

## 6. Mentor hop

The token, port, and session id come from `session-state.json`; missing token/state maps to `no_active_session`. The request names session and attempt. Server-side replay dedup is contractually `(attempt_id, phase)`; this client does not enforce it. Stale state is used; file mode is not checked.

**DEMONSTRATED** `packages/studyloop/src/studyloop/modules/hop.py:105-127` -- the existing fake-route test proves `message` (already rendered text) is sent despite M0 requiring typed fields only -- remove `message`; render solely from validated typed fields server-side.

**WEAKNESS** `packages/studyloop/src/studyloop/modules/hop.py:130-149` -- stale or world-readable state is accepted, and mode `0600` cannot hide the bearer token from a hostile same-UID module -- keep delivery credentials in a parent broker inaccessible to the child, validate owner/type/mode/freshness, and sandbox access to session state.

**WEAKNESS** `packages/studyloop/src/studyloop/cli/_drill.py:98-104` -- Lane C supplies `sha256:<64hex>`, but hop documents 64 hex and tests inject raw hex, risking rejection only after real integration -- define one canonical digest representation and test with Lane C's actual `LockEntry`.

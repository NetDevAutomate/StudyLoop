## 2. Naming standard

Branches retain the closed prefixes `feat/`, `fix/`, `docs/`, `test/`; `lane/` is reserved (`/Users/ataylor/code/personal/tools/studyloop/docs/contributing.md:174-180`). Commit subjects and PR titles use the closed types `feat|fix|test|docs|chore|ci`, optional **open** scope, colon, imperative outcome; ≤72 characters preferred. Scope is the smallest stable subsystem (`web`, `mcp`, `doctor`, `agents`); use `docs(openspec)` for specifications/change records and `docs(contributing)` for the published contributor journey; omit scope for genuinely cross-cutting work. Intermediate RED commits may say `test(scope): RED — …`; PR titles may not.

Worked normalizations from history: PR #40/`2883588f` → `fix(web): read completed WebSocket pull futures`; PR #41/`6b6a35bd` → `feat(learning-tier): record mentor learning events`; PR #42/`8d31f1ec` → `fix(gate): give coverage self-test its own timeout`; `e659f8cf` → `fix(web): give the voice probe a realistic budget`; `019624c3` → `fix(mcp): reject blank teach-back concepts and topics`; `60bbb504` → `docs(openspec): open the contributor-guide change`.

A PR description must name problem/outcome, issue, scope/out-of-scope, risk/migration/privacy, automated commands with actual results, manual/live evidence, docs/spec/changelog, AI assistance, and unverified work—extending the existing five evidence questions (`/Users/ataylor/code/personal/tools/studyloop/docs/contributing.md:271-286`).

- [ ] **Step 2: Update the canonical Second Brain spec**

Replace the obsolete wind-down requirement with normative requirements and scenarios covering:

```markdown
### Requirement: Wind-down decisions are provider-specific and connector-aware

At session wind-down the agent SHALL run `studyloop brain wind-down --json`,
including `--connector xtiles` only when a connector named exactly `xtiles` is
attached to that session.

- `provider: none` produces no offer.
- Configured, publish-capable Obsidian produces the pinned Obsidian publish offer.
- Configured xTiles produces the pinned xTiles offer only when connector
  `xtiles` is attached.
- Declining either offer produces no publish or connector write.
- An accepted xTiles flow writes the learning record to the source plan first,
  then invokes the assistant-owned xTiles connector.
- StudyLoop never becomes an xTiles API client and never stores xTiles credentials.
```

Preserve every existing containment, ownership, idempotence, and protocol requirement.
